# Beauty Galore Kenya – WordPress demo

A demo of the Beauty Galore Kenya site (jewellery, piercings by appointment and gifts, Westlands Commercial Center, Nairobi) that runs entirely in the browser with WordPress Playground. Built like our Aura Glow site: a block theme on Twenty Twenty-Five with jewellery and piercing prices as WooCommerce products, a WhatsApp bag and a piercing booking engine.

- Shop: https://playground.wordpress.net/?mode=seamless&blueprint-url=https://raw.githubusercontent.com/salvatorewanjohi-a11y/beauty-galore-demo/main/blueprint.json
- Admin (products, prices, photos): https://playground.wordpress.net/?mode=seamless&blueprint-url=https://raw.githubusercontent.com/salvatorewanjohi-a11y/beauty-galore-demo/main/blueprint-admin.json

Each visit builds a fresh copy, so changes are not kept.
